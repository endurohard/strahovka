# 🎮 Демо-режим веб-интерфейса

## Быстрый запуск без Docker

Если у вас не установлен Docker или вы хотите быстро посмотреть на веб-интерфейс, используйте демо-режим.

### Запуск

```bash
npm run demo
```

Или напрямую:

```bash
node demo.js
```

### Откройте в браузере

```
http://localhost:3000
```

## Что работает в демо-режиме

✅ **Доступные функции:**
- Просмотр клиентов (3 тестовых клиента)
- Поиск и фильтрация
- Сортировка
- Добавление нового клиента
- Удаление клиента
- Статистика в реальном времени
- Пагинация
- Responsive дизайн

❌ **Недоступно:**
- База данных PostgreSQL (используются тестовые данные в памяти)
- WhatsApp интеграция
- Импорт из Excel файлов
- Загрузка файлов

## Тестирование функций

### 1. Просмотр клиентов
Откройте http://localhost:3000 - увидите таблицу с клиентами

### 2. Поиск
Введите имя или номер телефона в поле поиска

### 3. Добавление клиента
1. Нажмите "Добавить клиента"
2. Заполните форму
3. Нажмите "Добавить"
4. Клиент появится в таблице

### 4. Удаление клиента
Нажмите на иконку корзины рядом с клиентом

### 5. Сортировка
Выберите вариант сортировки из выпадающего списка

## Остановка демо-режима

Нажмите `Ctrl+C` в терминале

Или найдите процесс:

```bash
# Найти процесс
lsof -i :3000

# Остановить процесс
kill -9 <PID>
```

## Полная версия

Для запуска полной версии с базой данных и WhatsApp:

```bash
# Запустите Docker Desktop
# Затем выполните:
docker-compose up -d
```

Откройте http://localhost:3000

## API в демо-режиме

Все API endpoints работают с тестовыми данными:

```bash
# Статистика
curl http://localhost:3000/api/stats

# Список клиентов
curl http://localhost:3000/api/clients

# Создать клиента
curl -X POST http://localhost:3000/api/clients \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Тестовый Клиент",
    "phone": "89991234567",
    "insurance": "Тест",
    "start_date": "2025-01-01",
    "amount": 5000
  }'

# Удалить клиента
curl -X DELETE http://localhost:3000/api/clients/1
```

## Для разработчиков

Демо-режим полезен для:
- Тестирования фронтенда
- Демонстрации интерфейса
- Разработки новых функций
- Проверки дизайна

Файл `demo.js` содержит упрощенную версию API без зависимостей от базы данных и WhatsApp.

## Переход на полную версию

Когда будете готовы к полной версии:

1. Установите Docker Desktop
2. Запустите `docker-compose up -d`
3. Отсканируйте QR код для WhatsApp
4. Импортируйте данные из Excel

Все данные, созданные в демо-режиме, не сохраняются и существуют только в памяти.
