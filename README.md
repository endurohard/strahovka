# Сервис напоминаний о продлении страховки через WhatsApp

Автоматический сервис для напоминания клиентам о необходимости продления страховки через WhatsApp Web.

## Возможности

- 🌐 **Веб-интерфейс для управления** - удобный дашборд с полным контролем
- 📊 Статистика в реальном времени
- 👥 Управление клиентами через браузер
- 📁 Чтение данных клиентов из Excel файла
- 🤖 Автоматический расчет даты окончания страховки (через год от даты начала)
- 📅 Напоминание клиентам за неделю до окончания страховки
- 📱 Отправка сообщений через WhatsApp Web
- 💾 Хранение данных в PostgreSQL базе данных
- ⏰ Планировщик для автоматической проверки и отправки напоминаний
- 🐳 Запуск в Docker контейнерах
- 🔍 Поиск и фильтрация клиентов
- 📤 Загрузка Excel файлов через интерфейс

## Требования

- Docker и Docker Compose
- Excel файл с данными клиентов

## Структура Excel файла

Файл должен содержать следующие столбцы (начиная со 2-й строки):

| № | Дата | Клиент | Номер телефона | Страховая | Услуги | Сумма |
|---|------|--------|----------------|-----------|--------|-------|
| 1 | 01.11.2025 | Иванов Иван | 89091234567 | Ингос | | 5200 |

- **Дата** - дата начала страховки (в формате Excel)
- **Клиент** - ФИО клиента
- **Номер телефона** - номер телефона в формате 89XXXXXXXXX
- **Страховая** - название страховой компании

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone <repository-url>
cd strahovka
```

### 2. Создайте директорию для данных

```bash
mkdir -p data
```

### 3. Скопируйте Excel файл

Поместите ваш Excel файл с данными клиентов в директорию `data/` с именем `clients.xlsx`:

```bash
cp /path/to/your/file.xlsx data/clients.xlsx
```

### 4. Настройте переменные окружения (опционально)

```bash
cp .env.example .env
# Отредактируйте .env при необходимости
```

### 5. Запустите сервис

```bash
docker-compose up -d
```

### 6. Авторизация в WhatsApp

При первом запуске вам нужно отсканировать QR код для авторизации в WhatsApp Web:

```bash
docker-compose logs -f app
```

Вы увидите QR код в терминале. Отсканируйте его через WhatsApp на телефоне:

1. Откройте WhatsApp на телефоне
2. Нажмите на три точки (меню)
3. Выберите "Связанные устройства"
4. Нажмите "Привязать устройство"
5. Отсканируйте QR код

После успешной авторизации сессия будет сохранена, и при следующих запусках авторизация не потребуется.

### 7. Откройте веб-интерфейс

Откройте браузер и перейдите на:

```
http://localhost:3000
```

Вы увидите дашборд с статистикой и управлением клиентами.

📖 **Подробная документация по веб-интерфейсу:** [WEB_INTERFACE.md](./WEB_INTERFACE.md)

## Расписание

По умолчанию сервис работает по следующему расписанию:

- **09:00** - обновление данных из Excel файла
- **10:00** - проверка и отправка напоминаний

Время можно изменить в файле `index.js` (строки с `cron.schedule`).

## Как работает сервис

1. **Импорт данных**: Сервис читает Excel файл и импортирует данные клиентов в базу данных
2. **Расчет дат**:
   - Дата окончания страховки = Дата начала + 1 год
   - Дата напоминания = Дата окончания - 7 дней
3. **Проверка**: Каждый день в 10:00 сервис проверяет, есть ли клиенты, которым нужно отправить напоминание
4. **Отправка**: Если дата напоминания совпадает с текущей датой, сервис отправляет сообщение через WhatsApp

## Формат сообщения

```
Здравствуйте, Иванов Иван!

Напоминаем, что срок действия вашей страховки (Ингос) истекает 01.11.2026.

Для продления страховки, пожалуйста, свяжитесь с нами.

Спасибо, что выбираете наши услуги!
```

## Устранение неполадок

### QR код не отображается

Попробуйте перезапустить контейнер:

```bash
docker-compose restart app
docker-compose logs -f app
```

### Сообщения не отправляются

1. Проверьте, что WhatsApp авторизован (см. логи)
2. Убедитесь, что номера телефонов в правильном формате (79XXXXXXXXX)
3. Проверьте подключение к интернету

### База данных не подключается

Убедитесь, что контейнер с PostgreSQL запущен:

```bash
docker-compose ps
```
