Сервис напоминаний о страховке

Статус: Сервер запущен на порту 3000

Попробуйте открыть в браузере:

Вариант 1: localhost

http://localhost:3000

Вариант 2: 127.0.0.1

http://127.0.0.1:3000

🧪 Проверка подключения

📋 Инструкции

  1. Кликните на одну из ссылок выше
  2. Если не открывается, скопируйте адрес и вставьте в браузер
  3. Попробуйте разные браузеры (Chrome, Safari, Firefox)
  4. Используйте кнопки "Тест" для проверки

🔧 Если не работает

В терминале выполните:

curl http://127.0.0.1:3000/api/health

Если увидите JSON с "status":"ok", значит сервер работает

• Откройте TROUBLESHOOTING.md для подробных инструкций

• Проверьте что порт 3000 не занят другой программой

• Попробуйте перезапустить: npm run demo
