# Веб-интерфейс для управления

## Описание

Веб-интерфейс предоставляет удобный способ управления сервисом напоминаний о страховке через браузер.

## Возможности

### 📊 Дашборд
- Общая статистика по клиентам
- Количество предстоящих напоминаний
- Количество ожидающих отправки
- Количество отправленных сообщений
- Статус подключения WhatsApp

### 👥 Управление клиентами
- Просмотр всех клиентов в таблице
- Поиск по имени или телефону
- Сортировка по различным полям
- Пагинация (50 клиентов на страницу)
- Добавление нового клиента
- Редактирование данных клиента
- Удаление клиента

### 📁 Работа с данными
- Импорт из Excel файла (/data/clients.xlsx)
- Загрузка нового Excel файла через интерфейс
- Автоматический расчет дат напоминаний

### 📨 Отправка напоминаний
- Ручная отправка напоминаний клиентам
- Просмотр статуса отправки
- Уведомления об успешной/неуспешной отправке

## API Endpoints

### Здоровье системы
```
GET /api/health
```
Возвращает статус системы и подключений

### Статистика
```
GET /api/stats
```
Возвращает общую статистику по клиентам

### Клиенты

**Получить список клиентов**
```
GET /api/clients?page=1&limit=50&search=&sort=reminder_date
```

**Получить клиента по ID**
```
GET /api/clients/:id
```

**Создать клиента**
```
POST /api/clients
Content-Type: application/json

{
  "name": "Иванов Иван",
  "phone": "89091234567",
  "insurance": "Ингос",
  "start_date": "2025-01-01",
  "amount": 5000
}
```

**Обновить клиента**
```
PUT /api/clients/:id
Content-Type: application/json

{
  "name": "Иванов Иван Иванович",
  "insurance": "Альфа"
}
```

**Удалить клиента**
```
DELETE /api/clients/:id
```

### Импорт и загрузка

**Импорт из Excel**
```
POST /api/import
```
Импортирует данные из файла /data/clients.xlsx

**Загрузить Excel файл**
```
POST /api/upload
Content-Type: multipart/form-data

file: <файл>
```

### Отправка сообщений

**Отправить напоминания**
```
POST /api/send-reminders
```
Отправляет напоминания всем клиентам, у которых reminder_date = сегодня

**Тестовая отправка**
```
POST /api/send-test
Content-Type: application/json

{
  "phone": "79091234567",
  "message": "Тестовое сообщение"
}
```

### WhatsApp

**Статус WhatsApp**
```
GET /api/whatsapp/status
```
Возвращает статус подключения WhatsApp

## Использование интерфейса

### 1. Первый запуск

После запуска сервиса откройте браузер и перейдите на http://localhost:3000

### 2. Импорт данных

Нажмите кнопку **"Импорт из Excel"** для загрузки данных из файла `/data/clients.xlsx`

### 3. Просмотр клиентов

Все клиенты отображаются в таблице с информацией:
- Имя
- Телефон
- Страховая компания
- Дата начала страховки
- Дата окончания страховки
- Дата напоминания
- Статус отправки

### 4. Поиск и фильтрация

Используйте поле поиска для фильтрации клиентов по имени или номеру телефона.

Выберите сортировку:
- По дате напоминания
- По имени
- По дате добавления

### 5. Добавление клиента

1. Нажмите **"Добавить клиента"**
2. Заполните форму:
   - Имя (обязательно)
   - Телефон (обязательно, формат: 89091234567)
   - Страховая компания (обязательно)
   - Дата начала (обязательно)
   - Сумма (опционально)
3. Нажмите **"Добавить"**

Даты окончания и напоминания рассчитаются автоматически.

### 6. Загрузка нового Excel файла

1. Нажмите **"Загрузить файл"**
2. Выберите Excel файл (.xlsx, .xls)
3. Нажмите **"Загрузить"**

Данные будут автоматически импортированы в базу.

### 7. Отправка напоминаний

Нажмите **"Отправить напоминания"** для отправки сообщений всем клиентам, у которых дата напоминания = сегодня.

**Важно:** WhatsApp должен быть подключен (зеленый статус в верхнем правом углу).

### 8. Обновление данных

Нажмите **"Обновить"** для перезагрузки таблицы клиентов и статистики.

## Статусы клиентов

- **Запланировано** (синий) - дата напоминания в будущем
- **Ожидает** (оранжевый) - дата напоминания сегодня или прошла, но сообщение не отправлено
- **Отправлено** (зеленый) - напоминание уже отправлено

## Уведомления

Интерфейс показывает уведомления о всех действиях:
- ✅ Успешные операции (зеленый)
- ❌ Ошибки (красный)
- ℹ️ Информация (синий)
- ⚠️ Предупреждения (оранжевый)

Уведомления автоматически исчезают через 5 секунд.

## Безопасность

### Рекомендации для production:

1. **Добавить аутентификацию**
```javascript
// Пример с Basic Auth
app.use((req, res, next) => {
  const auth = req.headers.authorization;
  if (!auth || auth !== 'Basic ' + Buffer.from('username:password').toString('base64')) {
    res.status(401).send('Authentication required');
    return;
  }
  next();
});
```

2. **Использовать HTTPS**
```bash
# С Nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:3000;
    }
}
```

3. **Ограничить доступ по IP**
```javascript
const allowedIPs = ['127.0.0.1', '192.168.1.100'];

app.use((req, res, next) => {
  const clientIP = req.ip;
  if (!allowedIPs.includes(clientIP)) {
    return res.status(403).send('Access denied');
  }
  next();
});
```

4. **Rate limiting**
```bash
npm install express-rate-limit
```

```javascript
const rateLimit = require('express-rate-limit');

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 минут
  max: 100 // лимит 100 запросов с IP
});

app.use('/api/', limiter);
```

## Разработка

### Локальный запуск (без Docker)

```bash
# Установка зависимостей
npm install

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env (установите DB_HOST=localhost)

# Запуск
npm start
```

Интерфейс будет доступен на http://localhost:3000

### С Docker

```bash
docker-compose up -d
```

Интерфейс будет доступен на http://localhost:3000

```yaml
ports:
```

Отредактируйте файлы:

### Добавление новых функций

1. Добавить endpoint в `api.js`
2. Добавить функцию в `public/app.js`
3. Добавить кнопку/элемент в `public/index.html`

## Устранение неполадок

### Интерфейс не открывается

1. Проверьте, что контейнер запущен:
```bash
docker-compose ps
```

2. Проверьте логи:
```bash
docker-compose logs -f app
```

3. Проверьте порт:
```bash
curl http://localhost:3000/api/health
```

### API возвращает ошибки

1. Проверьте подключение к базе данных
2. Проверьте статус WhatsApp
3. Посмотрите логи сервера

### WhatsApp не подключается

1. Проверьте логи:
```bash
docker-compose logs -f app | grep WhatsApp
```

2. Убедитесь, что QR код был отсканирован
3. Перезапустите контейнер:
```bash
docker-compose restart app
```
