# Сводка проекта: Сервис напоминаний о страховке

## Что создано

### Полнофункциональный сервис для автоматических напоминаний клиентам о продлении страховки через WhatsApp.

## Основные возможности

1. ✅ **Чтение данных из Excel файла**
   - Автоматический парсинг XLSX
   - Преобразование дат Excel
   - Форматирование номеров телефонов

2. ✅ **База данных PostgreSQL**
   - Хранение информации о клиентах
   - Автоматический импорт и обновление данных
   - Отслеживание отправленных напоминаний
   - Уникальность по телефону + дате начала

3. ✅ **Интеграция с WhatsApp Web**
   - Авторизация через QR код
   - Автоматическая отправка сообщений
   - Сохранение сессии между перезапусками
   - Персонализированные сообщения

4. ✅ **Автоматический планировщик**
   - 09:00 - обновление данных из Excel
   - 10:00 - проверка и отправка напоминаний
   - Настраиваемое расписание

5. ✅ **Docker контейнеризация**
   - Docker Compose для легкого развертывания
   - Персистентное хранение данных
   - Изоляция сервисов
   - Простое масштабирование

## Технологии

- **Node.js 18** - Серверная платформа
- **PostgreSQL 15** - База данных
- **WhatsApp Web.js** - WhatsApp интеграция
- **Puppeteer** - Автоматизация браузера
- **XLSX** - Работа с Excel
- **Node-Cron** - Планировщик задач
- **Docker & Docker Compose** - Контейнеризация

## Алгоритм работы

### 1. Расчет дат
```
Дата начала (из Excel) → +1 год → Дата окончания
Дата окончания → -7 дней → Дата напоминания
```

**Пример:**
- Дата начала: 01.11.2025
- Дата окончания: 01.11.2026
- Дата напоминания: 25.10.2026

### 2. Ежедневный цикл
```
09:00 → Импорт данных из Excel → Обновление БД
10:00 → Проверка reminder_date == сегодня → Отправка через WhatsApp
```

### 3. Отправка сообщений
```
Для каждого клиента:
  1. Создать персонализированное сообщение
  2. Отправить через WhatsApp Web
  3. Отметить в БД (last_reminder_sent)
  4. Задержка 2-3 секунды
```

## Быстрый старт

### 1. Подготовка
```bash
cd strahovka
# Excel файл уже скопирован в data/clients.xlsx
```

### 2. Запуск
```bash
docker-compose up -d
```

### 3. Авторизация WhatsApp
```bash
docker-compose logs -f app
# Сканируйте QR код в терминале через WhatsApp
```

### 4. Проверка
```bash
# Импорт данных
docker-compose exec app node index.js --import

# Проверка статистики
./check-db.sh

# Тестовая отправка напоминаний
docker-compose exec app node index.js --check-now
```

## Формат Excel файла

### Требуемые столбцы (со 2-й строки):
| № | Дата | Клиент | Номер телефона | Страховая | Услуги | Сумма |
|---|------|--------|----------------|-----------|--------|-------|

**Обязательные поля:**
- **Дата** - дата начала страховки
- **Клиент** - ФИО клиента
- **Номер телефона** - формат 89XXXXXXXXX
- **Страховая** - название страховой компании

## Формат сообщения

```
Здравствуйте, Иванов Иван!

Напоминаем, что срок действия вашей страховки (Ингос)
истекает 01.11.2026.

Для продления страховки, пожалуйста, свяжитесь с нами.

Спасибо, что выбираете наши услуги!
```

## Основные команды

### Управление Docker
```bash
docker-compose up -d              # Запуск в фоне
docker-compose down              # Остановка
docker-compose logs -f app       # Логи приложения
docker-compose restart app       # Перезапуск
```

### Работа с данными
```bash
docker-compose exec app node index.js --import     # Импорт
docker-compose exec app node index.js --check-now  # Проверка
./check-db.sh                                      # Статистика
```

### База данных
```bash
# Подключение к PostgreSQL
docker-compose exec db psql -U postgres -d strahovka

# Просмотр клиентов
docker-compose exec db psql -U postgres -d strahovka \
  -c "SELECT name, phone_formatted, reminder_date FROM clients;"
```
