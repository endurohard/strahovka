# 🚀 НАЧНИТЕ ЗДЕСЬ

## Что это?

Автоматический сервис для напоминания клиентам о продлении страховки через WhatsApp с **веб-интерфейсом для управления**.

## Что он делает?

1. 🌐 **Веб-интерфейс** - управляйте всем через браузер
2. 📊 Показывает статистику в реальном времени
3. 📁 Читает данные клиентов из Excel файла
4. 🤖 Рассчитывает дату окончания страховки (через год)
5. 📅 За неделю до окончания отправляет напоминание в WhatsApp
6. ⏰ Работает автоматически каждый день

## 📋 Быстрый старт за 3 шага

### Шаг 1: Убедитесь что Excel файл на месте

```bash
ls -lh data/clients.xlsx
```

Если файла нет, скопируйте его:
```bash
cp /path/to/your/file.xlsx data/clients.xlsx
```

### Шаг 2: Запустите сервис

```bash
docker-compose up -d
```

### Шаг 3: Авторизуйтесь в WhatsApp

```bash
docker-compose logs -f app
```

Отсканируйте QR код который появится в терминале через WhatsApp на телефоне.

**Готово!** 🎉 Сервис запущен и работает.

### Шаг 4: Откройте веб-интерфейс

Откройте браузер и перейдите на:

```
http://localhost:3000
```

Вы увидите красивый дашборд с:
- 📊 Статистикой клиентов
- 👥 Таблицей всех клиентов
- 🔍 Поиском и фильтрацией
- ➕ Кнопками для всех действий

## 📖 Что дальше?

### Использование веб-интерфейса (рекомендуется)

1. **Импортируйте данные** - нажмите "Импорт из Excel"
2. **Просматривайте клиентов** - все в таблице с поиском
3. **Добавляйте клиентов** - кнопка "Добавить клиента"
4. **Отправляйте напоминания** - кнопка "Отправить напоминания"
5. **Загружайте новые файлы** - кнопка "Загрузить файл"

📖 **Подробная документация:** [WEB_INTERFACE.md](./WEB_INTERFACE.md)

### Использование командной строки

### Проверить что данные загрузились

```bash
docker-compose exec app node index.js --import
./check-db.sh
```

### Протестировать отправку напоминаний

```bash
docker-compose exec app node index.js --check-now
```

### Остановить сервис

```bash
docker-compose down
```

## 🔧 Настройка

### Расписание (по умолчанию)

- **09:00** - обновление данных из Excel
- **10:00** - отправка напоминаний

Изменить можно в файле `index.js`

### Переменные окружения

Файл `.env` (уже настроен):
```env
DB_HOST=db
DB_PORT=5432
DB_NAME=strahovka
DB_USER=postgres
DB_PASSWORD=postgres
EXCEL_FILE_PATH=/data/clients.xlsx
TZ=Europe/Moscow
```

## ⚠️ Важно

1. **Первый запуск:** Нужно отсканировать QR код
2. **После этого:** Сессия сохраняется, повторная авторизация не нужна
3. **Обновление Excel:** Просто замените файл в `data/` и запустите импорт
4. **База данных:** Данные сохраняются между перезапусками
