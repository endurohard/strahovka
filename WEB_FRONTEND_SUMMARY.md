# 🌐 Веб-интерфейс добавлен!

## Что добавлено

### 🎨 Современный веб-интерфейс
- Красивый дашборд с статистикой в реальном времени
- Управление клиентами через браузер
- Responsive дизайн (работает на всех устройствах)
- Tailwind CSS для стилизации
- Font Awesome иконки

### 🔧 API сервер (Express.js)
- RESTful API для всех операций
- CORS поддержка
- Загрузка файлов (multer)
- Обработка ошибок
- JSON responses

## 🚀 Как использовать

### 1. Запуск
```bash
docker-compose up -d
```

### 2. Открыть в браузере
```
http://localhost:3000
```

### 3. Доступные функции

#### 📊 Дашборд
- Всего клиентов
- Предстоящие напоминания
- Ожидают отправки
- Уже отправлено
- Статус WhatsApp

#### 👥 Управление клиентами
- Просмотр всех клиентов
- Поиск по имени/телефону
- Сортировка
- Добавление нового клиента
- Удаление клиента
- Пагинация (50 на страницу)

#### 📤 Действия

- **Отправить напоминания** - отправить сообщения клиентам
- **Загрузить файл** - загрузить новый Excel через интерфейс
- **Добавить клиента** - создать клиента вручную
- **Обновить** - обновить данные

## 🎯 API Endpoints

### Клиенты
```
GET    /api/clients          - Список клиентов
GET    /api/clients/:id      - Один клиент
POST   /api/clients          - Создать клиента
PUT    /api/clients/:id      - Обновить клиента
DELETE /api/clients/:id      - Удалить клиента
```

### Действия
```
GET  /api/stats              - Статистика
GET  /api/health             - Здоровье системы
POST /api/import             - Импорт из Excel
POST /api/upload             - Загрузить Excel файл
POST /api/send-reminders     - Отправить напоминания
POST /api/send-test          - Тестовая отправка
GET  /api/whatsapp/status    - Статус WhatsApp
```

## 📝 Использование

### Добавить клиента вручную
1. Нажмите "Добавить клиента"
2. Заполните форму
3. Даты рассчитаются автоматически
4. Нажмите "Добавить"

### Загрузить Excel файл
1. Нажмите "Загрузить файл"
2. Выберите .xlsx файл
3. Нажмите "Загрузить"
4. Данные импортируются автоматически

### Отправить напоминания
1. Убедитесь что WhatsApp подключен (зеленый статус)
2. Нажмите "Отправить напоминания"
3. Подтвердите действие
4. Увидите результат в уведомлении

## 🎓 Кастомизация

### Изменить порт
В `.env`:
```env
API_PORT=8080
```

### Изменить дизайн
- Отредактируйте `public/index.html`
- Измените Tailwind классы
- Добавьте свои CSS стили

### Добавить новую функцию
1. Добавьте endpoint в `api.js`
2. Добавьте функцию в `public/app.js`
3. Добавьте кнопку в `public/index.html`
